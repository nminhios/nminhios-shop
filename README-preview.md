# nminhios store — Bản xem trước tĩnh

- Mở `index.html` hoặc tải toàn bộ thư mục này lên hosting tĩnh (ví dụ GitHub Pages).
- Đây là bản DEMO: sản phẩm, giỏ hàng, người dùng và đơn hàng demo lưu ở trình duyệt; chưa phải giao dịch thật.
- Không nhập thông tin bí mật hoặc dữ liệu khách hàng thật vào bản demo.
- Muốn chạy thật, dùng gói `nminhios-store-fullstack.zip`, thiết lập `.env` và triển khai Node.js backend theo README.
- Thanh toán thật cần tích hợp và kiểm thử webhook đúng tài liệu nhà cung cấp.
